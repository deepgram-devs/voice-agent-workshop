# Troubleshooting

The full table. The README's [Troubleshooting](../README.md#troubleshooting) has the rows every language hits on a first run, and each language's page has its own ([Python](python.md#troubleshooting), [TypeScript](typescript.md#troubleshooting), [Java](java.md#troubleshooting)). This page has every line the helpers and the checks print, the workshop-token codes, the proxy's lines, and make's own lines that stop a command. Find the line you see in the first column, read what it means, apply the fix, carry on. In output pasted from a pipe or a log, `make`'s own `*** Error` line and the `[credentials]` line can sit above the line they follow on a terminal: search for the helper's words, not the order. Each mission brief has a shorter Stuck? table for that mission's own failures.

## Your .env

`make setup` copies `.env.example` to `.env` in the project folder, and Git ignores `.env`. Every line is `KEY=value` with no spaces around the `=`. Paste values with no quotes: quotes around a whole value are read too, with nothing after the closing quote but a `# comment`. Words after a closing quote, or a quote that never closes, stop the program with one line saying so (your language's row below); in Docker, Docker Compose usually stops first, before the container, with its own `failed to read` line (two rows below).

## Workshop token

A token lasts 8 hours or until the workshop's live agent closes, whichever comes first, and runs one program at a time: starting a second one closes the first. Getting a new token replaces the old one, and workshop staff can turn a token off. The proxy uses the same settings rules as the web missions: a listen model, LLM (large language model: the `think` layer) or voice outside its list comes back as a `Warning`, and the default is used; a feature the workshop has switched off is left out, with a `FEATURE_OFF` warning. When the workshop can't take a conversation right now, your program prints one `[workshop]` line with the reason and the next step, then stops. After the event, a token's sessions are refused with `LIVE_CLOSED` while the proxy route is still up, and with `HTTP 404` once the workshop turns the route off. Each code is a row below. The no-helpers example (`examples/first_settings.py` and its siblings) reads your own key only: it has no token path and belongs to no mission.
